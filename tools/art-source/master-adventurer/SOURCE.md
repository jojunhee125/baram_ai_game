## Runtime source

`pixels.json` contains the curated native pixel grid, embedded palette, and per-frame origins. The final drawing is constructed in this grid; it is not a resized copy of the generated candidate. `../../prepare-master-avatar.mjs` compiles the grid into `../../../assets/sprites/master-adventurer.png` and the atlas/comparison sheets under `../../../docs/art/`.

The runtime contract is 16 cells at 48×48 pixels in a 192×192 atlas, rows down/left/right/up, columns idle/left-step/passing/right-step, foot anchor (24, 46). This resolution is a proposed project standard, not a verified historical game source resolution. Dedicated attack, cast, hit, and death artwork is not included.

Run `node tools/prepare-master-avatar.mjs` from the repository root to regenerate the files, or append `--check` to compare regenerated bytes with the checked-in outputs.
